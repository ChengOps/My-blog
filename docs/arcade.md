# 隐藏的游戏小屋

连续点击页头头像：每次间隔不超过 1 秒，第 5 次说「你再点一次试试」，第 8 次说「真拿你没办法」，停留 900ms 后进入 `/play`。等待期间重复点击不会再次导航；离开页面会清理定时器。点击名字仍返回首页；聚焦头像后按 Enter / 空格同样有效。未解锁时点击其他位置会打断序列。游戏页不进入 sitemap，也不参与搜索索引；彩蛋是惊喜入口，不是权限控制。

## 两个小游戏

- **扫雷**：6×6 棋盘，关卡 1–5 分别放置 4 / 5 / 6 / 7 / 8 颗雷。首击及周围一圈保证安全，空白区域自动展开。揭开所有安全格即通关，不要求插完全部旗；数字表示相邻八格中的雷数。难度为简单，但不承诺每盘都能仅凭逻辑推断，无撤回。无尽模式每盘 6 颗雷，清空后等待 600ms 进入新盘；按累计揭开的安全格排名，插旗不加分，触雷结束。
- **2048**：经典 4×4，**只有无尽模式，没有关卡**。初始两个方块，每次有效移动后随机生成 2（90%）或 4（10%），无效移动不出新块。同值方块合并，每个方块每步只能合并一次，合并后的值计入得分。达成 2048 后可以继续；棋盘填满且无相邻同值时结束。七种动物对应不同数值，数字始终是主要线索。

扫雷支持点击揭开、手机「切换插旗」、鼠标右键或 F 插旗；棋盘内方向键移动焦点，Enter / 空格操作。2048 支持方向键、棋盘内指针滑动和四个方向按钮；只有棋盘阻止触屏页面滚动。游戏区以外仍能正常滚动，Tab / Escape 不被拦截。

关卡榜按每关通关毫秒数升序；扫雷无尽榜按累计安全格、2048 无尽榜按合并得分降序，同分按用时升序。无尽模式可主动结算。单局最多 30 分钟或 3998 次有效操作后自动结算；2048 的「无尽」表示无关卡目标，仍受此会话上限约束。首次通关、个人最佳与登榜 / 排名上升分别有印章、角色轻跳与文字反馈。装饰动效只改变 transform / opacity，Hush 和减少动态效果均可关闭。空白点击特效限定游戏页，最多保留 5 个节点，动画结束、取消、卸载均清理。

本机最佳使用 `xavier-arcade-records-v4`，旧版本机记录保留但不参与比较。线上通过 `mines-v4` / `2048-v4` 单独排名，重跑 `supabase/arcade.sql` 扩展约束和得分范围；旧成绩不删除。2048 关卡配置在界面、接口和数据库均不接受。旧游戏 ID 与旧规则凭证不能提交新版成绩。昵称与头像仍使用 `xavier-arcade-identity`，首次可沿用留言选择，但不更改留言偏好。关闭本机存储仍能玩，无法持久化时有提示。

## 开启线上榜：沿用现有 Supabase

1. 在同一个 Supabase 项目 SQL Editor 执行 `supabase/arcade.sql`；脚本可重复执行，不影响留言表。
2. 配置现有 `SUPABASE_URL`、`SUPABASE_SERVICE_ROLE_KEY`、`COMMENTS_IP_SALT`（至少 32 字符），重新部署。没有配置时 API 返回 503，游戏和本机纪录仍可用，界面不会伪造线上排名。
3. 玩家结束后主动点「用当前昵称提交到线上榜」。每个浏览器匿名身份、每个游戏、模式和关卡只保留最佳成绩。清除 Cookie 或更换浏览器会成为新身份，不提供跨设备账号同步。

浏览器没有数据库权限。服务端签发种子及一小时有效的 HMAC 凭证，绑定 HttpOnly / SameSite Cookie；回放操作，计算布雷、展开、插旗、数字合并、出块和最终分数，不接收自报分数。跨站、超长输入、篡改 / 过期凭证、非法操作、终局后操作和未通关提交会被拒绝；数据库原子地防止重复提交，限每身份每分钟 15 次。它是休闲友好榜，无法防住脚本解题或匿名多身份刷榜，不用于奖品和竞技。

不合适的昵称可在 Supabase 将对应 `arcade_scores.hidden` 设为 `true`；隐藏状态在重玩时保留。成绩与匿名浏览器标识保存在 Supabase；不保存操作日志及 IP。`arcade_runs` 只保存已提交的凭证 ID 与身份用于去重，可定期清理超过 30 天的数据（凭证一小时即过期）。

验证：`pnpm test` 覆盖首击安全、展开 / 插旗 / 触雷、无尽续盘、2048 四方向合并 / 出块 / 无效移动、确定性回放、规则凭证与成绩反馈；`pnpm lint && pnpm build`。线上真实名次与 SQL 需在填好项目配置后验收，本地无密钥时仅验收明确的离线降级。
